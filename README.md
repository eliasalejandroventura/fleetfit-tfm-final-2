# FleetFit — TFM FINAL 2

Independent application for the TFM_FINAL_2 research run. The fitted pipeline is the same pipeline evaluated in N02 Section 19 and exported without refitting in Sections 22–23.

Use Python 3.12 and follow [04_app/README.md](04_app/README.md). Streamlit entrypoint: `04_app/app.py`. The four required inference artifacts are included in `03_outputs/model/`. The app requires neither the research datasets nor notebook execution.

This package is separate from the original TFM_FINAL application. Open the verified public application: [https://fleetfit-tfm-final-2.streamlit.app/](https://fleetfit-tfm-final-2.streamlit.app/).

Source repository: [https://github.com/eliasalejandroventura/fleetfit-tfm-final-2](https://github.com/eliasalejandroventura/fleetfit-tfm-final-2).
